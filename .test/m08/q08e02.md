But why would we accept this?

To repair this injustice, you have to make the `std::stack` container iterable.

Write a **MutantStack** class. It will be implemented in therms of a `std::stack`. It will offer all its member functions, plus an additional feature: iterators.

Of course, you will write your own tests, and they will be far more thorought than the one below.

Find a test example below:

```cpp
int main()
{
  MutantStack<int>  mstack;

  mstack.push(5);
  mstack.push(17);

  std::cout << mstack.top() << std::endl;

  mstack.pop();

  std::cout << mstack.size() << std::endl;

  mstack.push(3);
  mstack.push(5);
  mstack.push(737);
  //[...]
  mstack.push(0);

  MutantStack<int>::iterator it = mstack.begin();
  MutantStack<int>::iterator ite = mstack.end();

  ++it;
  --it;
  while (it != ite)
  {
    std::cout << *it << std::endl;
    ++it;
  }
  std::stack<int> s(mstack);
  return 0;
}
```
If you run it a first time with your MutantStack class, and a second time replacing the MutantStack with, e.g., `std::list`, the output should be exactly the same.
