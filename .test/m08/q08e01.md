Develop a **Span** class that can store a maximum of N integers. N is an unsigned int variable and will be the only parameter of the constructor.

This class will have a member function called `addNumber()` that will add a single number to the Span. It will be used in order to fill the Span with numbers. Any attempt to add a new element if there are already N elements stored will throw an exception.

Next, implement two member functions: `shortestSpan()` and `longestSpan()`.

They will respectively find out the shortest span or the longest span (or distance) between all the numbers stored, and return it. If there are no numbers stored or only one, no span can be found, and an exception will be thrown.



Of course, you will write your own tests, and they will be far more thorought than the one below. Test your Span with at least 10,000 numbers. More would be even better.

Running this code:

```cpp
int main()
{
  Span sp = Span(5);

  sp.addNumber(6);
  sp.addNumber(3);
  sp.addNumber(17);
  sp.addNumber(9);
  sp.addNumber(11);

  std::cout << sp.shortestSpan() << std::endl;
  std::cout << sp.longestSpan() << std::endl;

  return 0;
}
```
