Can you help me with the My Awesome PhoneBook project at 42 School?

- Files to turn in: `*.cpp`, `*.{h, hppp}`, `Makefile`
- Forbidden functions: None

Write a program that behaves like a crappy awesome phonebook software.

Two classes should be implemented:
- PhoneBook
  - It has an array of contacts
  - It can store a maximum of 8 contacts. If the user tries to add a 9th contact, it should replace the oldest one.
  - Dynamic memory allocation is not allowed.
- Contact
  - Stands for a phonebook contact

The phonebook must be instantiated as an instance of the PhoneBook class.
Same thing for the contacts. Each one of them must be instantiated as an instance of the Contact class. Other classes can be created, but respect public/private access specifiers.

At program start-up the phonebook is empty and the user is prompted to enter one 
of three commands: ADD, SEARCH or EXIT.
- ADD: adds a new contact to the phonebook.
  - the user is prompted to input the information of the new contact (one field at a time). Once all the fileds have been entered, the user is brought back to the main prompt and the contact is saved in the phonebook.
  - the contact fields are:
    - first name
    - last name
    - nickname
    - phone number
    - darkest secret
  - A saved contact can't have empty fields.
- SEARCH: display a specific contact.
  - Display the saved contacts as a list of 4 columns: Index, First Name, Last Name, Nickname.
  - Each column must be 10 characters wide. A pipe character ('|') must separate each column. The text must be right aligned. If the text is longer than 10 characters, it must be truncated and the last displayed character must be a dot ('.')
  - After displaying the list, the user is prompted to enter the index of the desired contact. If the index is valid, display all the information of the selected contact (one field per line). If the index is invalid, display an error message and bring the user back to the main prompt.
- EXIT: exits the program (and the contacts are lost forever).
- Any other inputs are ignored.

Once a command has been executed, the program waits for another one.
It stops when the user inputs EXIT.

---

I don't have any experience with C++, but I know C and I know object-oriented programming concepts. Please explain me how to implement this in C++ and everything what is new to me compared to C.
